A3 — op-log replay cost: raw measured output

Recorded 2026-10-19. Apple M1 Ultra (20 cores), 128 GiB, macOS 25.6.0,
rustc 1.97.1, --release. The machine was shared with another agent's cargo
test run throughout, which is where the p99 noise on the largest read layer
comes from (85.5 ms in run 1, 106.9 ms in run 2, same configuration).

This is captured tool output, kept so the numbers are reproducible and
auditable rather than only quoted. Reproduce with:

  cargo build --release
  ./target/release/spike-oplog --ops 10,100,1000,10000 --body 1200 --format nested,flat --out target/spike-out
  ./target/release/spike-oplog --ops 10,100,1000,10000 --body 128,8000 --format nested --out target/spike-out
  python3 -I compressed_size.py target/spike-out
  python3 -I inflate_cost.py target/spike-out
