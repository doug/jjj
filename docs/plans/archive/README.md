# Archived plans

Design and implementation logs for work that has since shipped. They are kept
for provenance, not as documentation — several describe superseded designs
(most notably the quadratic-vote ranking that sized gaps replaced in 0.5.0).

**Do not treat anything here as current.** For how a subsystem works today, see
`docs/architecture/`, `docs/reference/`, and the design docs one level up in
`docs/design/`.
